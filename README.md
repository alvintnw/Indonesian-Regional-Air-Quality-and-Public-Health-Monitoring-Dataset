# Indonesian Regional Air Quality & Public Health Monitoring Dataset 🍃🇮🇩

An automated synthetic dataset and interactive analytics web dashboard tracking Air Quality Index (AQI), pollutant concentrations (PM2.5, PM10, CO, NO2), air quality status, and public health impact metrics across major urban centers in Indonesia.

## 📊 Dataset Features
*   **Scope:** Major cities and industrial urban hubs in Indonesia (Jakarta, Surabaya, Bandung, Medan, Semarang, Makassar, Tangerang, Bekasi, Depok, Palembang).
*   **Attributes:** Timestamp, City, Province, PM2.5 ($\mu g/m^3$), PM10 ($\mu g/m^3$), CO ($ppm$), NO2 ($ppb$), AQI Score, Air Quality Status (Good, Moderate, Unhealthy for Sensitive Groups, Unhealthy), and Dominant Pollutant.

## 🚀 App Features
*   **Executive Metrics:** Real-time summary of average AQI score, peak PM2.5 levels, monitored urban locations, and general air status overview.
*   **Interactive Visualizations:** Comparative bar charts for AQI levels across cities and scatter analysis for pollutant correlations using Plotly.
*   **Dynamic Filters:** Filter data effortlessly by city, air quality status, and dominant pollutant.
*   **Raw Data Explorer:** Search, filter, and download raw tabular data directly from the browser.
